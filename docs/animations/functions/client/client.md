# Client

## Open

Open animations menu.

```lua
exports.flexin_animations:Open()
```

## PlayAnimation

Play a specific animation.

```lua
exports.flexin_animations:PlayAnimation(Data)
```

- Data?: `table`
  - animation: `table`
    - name: `string`

## StopAnimation

Stop the current animation.

```lua
exports.flexin_animations:StopAnimation()
```
